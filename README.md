# self-introduction-practice

## 概要

COACHTECH 教材 Tutorial 5-1「HTMLの基礎 ハンズオン演習」で作成した成果物です。
自分のプロフィール、リンク先、簡単な問い合わせ

## 使用技術

- HTML5

## 学んだこと

- HTML5の基本構造
- 画像の探し方、貼り付け方法
- 問い合わせの作り方

## 動作確認

1. リポジトリからファイル一式をダウンロード（またはクローン）します。
2. `self-introduction.html` をGoogle ChromeなどのWebブラウザで開きます。
3. 画面に自己紹介ページが正しく表示されることを確認します。
